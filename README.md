# Laravel URL Shortener

This is the project where I started learning how to build APIs with Laravel.

## About

The goal of this repository is simple: practice Laravel fundamentals by creating a URL shortener API.

It is my learning playground for:
- API routing and controllers
- Request validation
- Database modeling with Eloquent
- Migrations and seeders
- Automated tests with Pest

## Tech Stack

- PHP
- Laravel
- PostgreSQL
- Pest
- Docker

## Learning Focus

This project is focused on improving backend development skills and understanding how real API workflows are built in Laravel.
